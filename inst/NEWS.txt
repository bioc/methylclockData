Changes in version 1.21.3
--------------------------
  - added the coefGarma resource: the cross-platform age model of Garma &
    Quintela-Fandino (2024), trained on probes shared by the 450K, EPICv1
    and EPICv2 arrays; its table includes squared-beta terms marked by a
    power column
  - the resource keeps its source licence (CC BY-NC-ND 4.0), as the deposit
    declares per resource; hosted on a new version of the same Zenodo
    deposit

Changes in version 1.21.2
--------------------------
  - the 28 resources added in 1.21.1 are now available from ExperimentHub
    (EH10460 to EH10487): their accessor functions carry the assigned ids
  - metadata_v2026_08.csv now records Location_Prefix as the Zenodo host
    and the record path in RDataPath, matching the form loaded into the
    ExperimentHub production database

Changes in version 1.21.1
--------------------------
  - added 28 resources for the clocks introduced in the methylclock
    redesign: DunedinPACE (coefficients and reference means), the four
    NEOage clocks, Vidal-Bralo, Lin, Weidner, the causal clocks CausAge,
    DamAge and AdaptAge, the mitotic counters epiTOC1, epiTOC2, HypoClock,
    stemTOC and RepliTali, the eight McCartney EpiScores, mCigarette, and
    the AltumAge network weights and input CpG order
  - these resources are hosted on Zenodo, doi:10.5281/zenodo.21840402; the
    ones published previously are unchanged
  - each resource keeps the licence of its original source, which are not
    uniform; see the Zenodo record for the licence of each one
  - rewrote the package description, which no longer matched its contents
